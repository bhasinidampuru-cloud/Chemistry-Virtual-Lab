# ⚡ E-CELL — Virtual Electrochemistry Lab

An interactive Engineering Chemistry virtual laboratory built with Python and Streamlit.

## Modules
- Home
- Galvanic Cell Simulator
- Nernst Equation Simulator
- Gibbs Free Energy Calculator
- Electrolysis Simulator
- Theory
- Quiz
- Experiment Report Generator
